Ardhan — Support

Ardhan is a single-player roguelike deck-building card game made by one independent developer.

Questions, bug reports and ideas:

contact@unitechdigital.net

Please write in English if you can. Every message is read.

What to put in your message

  • Where you play: Android, iPhone or iPad, Windows or Linux, and which store you got the game from.
  • The game version: it is shown at the bottom-right of the title screen.
  • Your device or computer model.
  • What you did, what you expected and what happened. A screenshot helps a lot.
  • On Windows or Linux, if the game crashed: attach the log file godot.log from the logs folder (see "Where your progress is saved" below).

Purchases and refunds

Payments and refunds are handled by the store where you paid. I cannot see your payment details and cannot refund a store purchase myself.

On every store the in-game shop has a "Restore purchases" button: if an item you bought is missing, make sure the store you bought it from is connected and signed in (on Steam: start the game from Steam), then press it. Items bought for money stay with the store account that bought them; shards, gold and deck slots travel with your save code (see "Your progress").

  • Google Play: Google Play refund help
  • App Store: reportaproblem.apple.com
  • Steam: help.steampowered.com
  • Microsoft Store: Microsoft Store refund help

Your progress

There is no account. Your progress is saved only on your device, so uninstalling the game on a phone or tablet deletes it. To keep it safe: open Settings, go to "Save backup", press "Copy save code" and keep the code somewhere private. "Import save code" puts it back later.

Where your progress is saved (Windows and Linux)

  • Windows (Steam): %APPDATA%\Godot\app_userdata\Ardhan\
  • Windows (Microsoft Store): the Ardhan folder inside %LOCALAPPDATA%\Packages\, then LocalCache\Roaming\Godot\app_userdata\Ardhan\
  • Linux and Steam Deck: ~/.local/share/Godot/app_userdata/Ardhan/

The save is save.json; the log is in the logs folder next to it. On Steam, uninstalling the game does not delete this folder. If Steam Cloud is on, Steam may also keep a copy in your Steam account. Uninstalling the Microsoft Store version deletes its folder, save included: copy your save code first.

Optional downloads

Some content (such as the story cinematics) is an optional download. If a download fails, check your internet connection and try again later from Settings. The game stays fully playable without it.

Privacy

No account, no ads, no analytics, no tracking. Read the full privacy policy.
